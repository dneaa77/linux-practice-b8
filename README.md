# Практическая работа № 8
## Вариант B — Алгоритмы синхронизации и взаимоблокировки

### Цель работы

Изучить алгоритм банкира, обнаружение взаимоблокировок, отслеживание блокировок потоков и способы предотвращения deadlock.

### 1. Алгоритм банкира

Файл: `banker.py`

Программа читает исходные данные из `data/banker.json`, вычисляет матрицу Need, проверяет безопасность системы и обрабатывает запросы ресурсов из стандартного ввода.

Если запрос приводит к небезопасному состоянию, программа отменяет изменения.

Запуск:

```bash
python3 banker.py
```

### 2. Детектор взаимоблокировок

Файл: `deadlock_detector.py`

Программа читает журнал событий `acquire`, `release` и `wait`, строит граф ожидания и ищет циклы с помощью DFS.

Запуск:

```bash
python3 deadlock_detector.py
```

### 3. Отслеживание блокировок

Файлы: `tracked_lock.py`, `deadlock.py`

Реализованы класс TrackedLock, граф ожидания потоков и исключение DeadlockError для обнаружения циклов ожидания.

Запуск:

```bash
python3 deadlock.py
```

### 4. Задача обедающих философов

Файл: `philosophers.py`

Реализованы три сценария:

- `deadlock` — демонстрация взаимоблокировки;
- `ordered` — предотвращение циклического ожидания с помощью нумерации вилок;
- `limited` — предотвращение взаимоблокировки с помощью ограничения числа философов, одновременно пытающихся получить вилки.

Запуск:

```bash
python3 philosophers.py --mode deadlock
python3 philosophers.py --mode ordered
python3 philosophers.py --mode limited
```

В каждом режиме выводится статистика приёмов пищи.

### Вывод

В ходе работы реализованы алгоритм банкира, поиск циклов в графе ожидания, отслеживание блокировок потоков и сравнение способов предотвращения взаимоблокировок.
